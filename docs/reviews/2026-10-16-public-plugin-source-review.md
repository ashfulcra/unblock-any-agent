## Fresh review and fix

A fresh read-only reviewer found zero Critical issues, one Important issue and no Minor issues. The current candidates were clean, but recursive content comparison followed symbolic links. Replacing a copied skill with a same-content link outside its plugin incorrectly passed the CI comparison on both platforms.

The accepted finding was fixed in one pass. CI now rejects any symlink in the published plugin directory before comparing generated bytes and trees. Negative probes reproduced the old acceptance, confirmed rejection for both copied skills, and also confirmed rejection when a symlink replaces the entire plugin directory. Clean candidates still pass. The author verified the fix; no repeat review was requested.
